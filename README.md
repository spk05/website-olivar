# Olivar Design | Architecture & Landscape

Welcome to the repository for **Olivar Design**, an architecture and landscape design studio specializing in premium leisure and recreational architecture. We create places where serenity, privacy, heritage, and greenery come together.

🌍 **Live Website:** [https://olivardesign.com/](https://olivardesign.com/)

## About the Project

Olivar Design is headquartered in Riyadh, Saudi Arabia, with an office in Arizona, United States. This repository contains the source code for the Olivar Design portfolio and landing page, featuring a fully bilingual (English / Arabic) user interface, smooth animations, and an immersive user experience.

### Core Services:
- **Architecture Design:** Spatial planning, material selection, and style development.
- **Interior Design:** Detailed space planning, material selection, finishes, and furniture integration.
- **Fit-Out:** Turnkey execution services from design to reality.

### Selected Works Featured:
- **The Olive Court** – Boutique Resort
- **Palm Horizon Resort** – Modern Resort
- **The Grove Retreat** – Leisure Architecture
- **The Rooted Rest House** – Private Villa
- **Malham Istiraha** – Private Retreat

## Technologies Used

- **HTML5 & CSS3:** Semantic markup, custom styling, CSS Grid/Flexbox layouts, and custom animations.
- **JavaScript (Vanilla):** Dynamic bilingual toggling, intersection observers for scroll animations, and interactive modals.
- **Vite:** Fast development server and optimized production builds.

## Getting Started

To run the project locally on your machine:

1. Clone the repository:
   ```bash
   git clone https://github.com/spk05/website-olivar.git
   ```
2. Navigate to the directory:
   ```bash
   cd website-olivar
   ```
3. Install dependencies:
   ```bash
   npm install
   ```
4. Start the development server:
   ```bash
   npm run dev
   ```
